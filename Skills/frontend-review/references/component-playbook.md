# 逐组件审查手册

## 组件索引与组合规则

| 页面特征 | 组合读取 |
|---|---|
| 设置或配置表单 | 读取 C01、C03–C09、C14、C29，并按出现的弹层读取 C10–C13 |
| 数据管理页 | 读取 C16、C18–C25、C29、C32，并检查每个行操作的 C01/C12 实例 |
| 文档工作台 | 读取 C11、C24、C26、C28、C32，并检查滚动、焦点与长会话 |
| AI 对话或训练任务 | 读取 C04、C25、C29–C32，并检查会话切换和取消的真实服务端语义 |
| 信息展示或公开页面 | 读取 C02、C16–C18、C27–C29；仅在需要搜索收录时增加 SEO 检查 |

- 先定位页面里的实际 UI 单元，再按适用条件读取对应 C 编号；一个单元可同时关联多个编号，例如把“可搜索的多选筛选器”按 C06、C21、C22 检查。
- 未命中索引的业务组件按相同标签建立实例记录并组合现有分支。
- 共享定义与页面实例的拆分见 [review-workflow.md](review-workflow.md)，状态词表与证据要求见 [ledger-contract.md](ledger-contract.md)。

## C01 按钮与图标按钮

- **适用条件：** 存在提交、确认、切换、重试、危险操作或图标触发器时执行。
- **状态：** 在异步动作中覆盖忙碌、失败可重试、成功与失去操作权限；忙碌时保留可发现的名称。
- **动作与反向中断：** 验证双击、按住 Enter 或空格、重复提交；忙碌时切页或取消，核对是否多次创建任务或误触发父级动作。
- **数据布局：** 换入最长已支持文案；spinner 出现不改变按钮宽高，图标、触摸目标与忙碌标签不遮挡相邻操作。
- **验收：** 键盘聚焦并激活；在受控慢响应下快速触发两次；核对可见反馈、真实动作次数与失败后可再次操作。
- **修复：** 修正 form 内按钮的 type 与默认提交路径；把忙碌状态绑定实际请求；对创建类动作与后端约定幂等键收敛重复提交。

## C02 链接与可导航区域

- **适用条件：** 存在内部导航、外部资源、可点击卡片或下载入口时执行。
- **状态：** 资源不存在、无权限或链接失效时检查目标行为与当前页表达。
- **动作与反向中断：** 验证普通打开、新标签、复制链接、刷新深链接与后退；卡片内子按钮触发导航时的实际结果。
- **验收：** 直接访问目标 URL 再前进后退；用键盘打开；目标资源失效时核对实际状态与返回路径。
- **修复：** 还原真实链接与路由契约；拆分卡片主导航与行内动作；外链与打开方式的信任边界见 [security-delivery.md](security-delivery.md)。

## C03 单行输入

- **适用条件：** 存在文本、密码、邮箱、标识符、数值文本或带格式输入时执行。
- **状态：** 覆盖空值、有值、只读与无效；异步校验中增加校验中、失效结果与接口错误。
- **动作与反向中断：** 验证粘贴、清空、撤销、自动填充与光标中部修改；校验未完成时改值或离开字段。
- **语义键盘：** 按字段目的设置 type、inputmode 与 autocomplete；保留密码管理器可用的粘贴与自动填充路径。
- **验收：** 核对提交值与显示值分别正确、过期校验结果被丢弃、错误指向当前字段；输入法候选与格式化中间态见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **修复：** 分离编辑文本与解析值，在合适时机格式化；丢弃已失效的校验结果。

## C04 多行文本与消息输入

- **适用条件：** 存在评论、长描述、聊天输入或自动增高输入区时执行。
- **状态：** 覆盖空白、换行、超限、草稿、发送中与失败；支持附件时检查正文与附件的组合限制。
- **动作与反向中断：** 发送后快速继续输入、切换会话、取消发送、恢复失败草稿；Enter、修饰键换行与输入法选词的按键序列见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **数据布局：** 检查自动增高上限与内部滚动；长度限制明确按字符、字节还是 token 计算。
- **验收：** 受控失败响应后核对草稿、附件与所属会话一致；切换会话时各输入区内容互不覆盖。
- **修复：** 按会话保存草稿；发送请求带稳定标识；成功响应只确认对应提交快照。

## C05 复选框单选与开关

- **适用条件：** 存在多选、互斥选择、布尔设置或全选控件时执行。
- **状态：** 在全选中覆盖部分选中，在即时保存中覆盖保存中与失败回滚；区分禁用与只读。
- **动作与反向中断：** 验证点击标签、键盘切换与快速连续切换；远程失败或选项失效后核对显示值与服务端保存值。
- **语义键盘：** 按单选组模式处理方向键；只有真正支持混合状态的控件才表达 mixed。
- **验收：** 从无选择切到部分、全部再取消；在分页或过滤后核对全选范围；一次保存失败后读取最终服务端值。
- **修复：** 明确当前页与全量选择语义；以稳定 ID 保存选择；失败的乐观状态回滚到服务端事实。

## C06 选择器与组合框

- **适用条件：** 存在原生 select、自定义下拉、可搜索选择或多选标签时执行。
- **状态：** 覆盖关闭、展开、选中与无结果；远程选项增加加载、失败、已选项被移除与过期查询。
- **动作与反向中断：** 验证展开、选择、取消、清空与点击外部；输入联想词后立刻换词、关闭或切页。
- **语义键盘：** 先确定模式是原生 select、combobox 还是 listbox，再按该模式落实活动选项关联、方向键、确认与 Esc；可选项用 option，命令项才用 menuitem。
- **数据布局：** 测试长选项、重名不同 ID、大量选项、多行标签与视口边缘位置。
- **验收：** 仅用键盘完成选取与取消；已选项不在当前结果中时核对显示名称与提交 ID。
- **修复：** 分离输入词、活动项与已选值；请求绑定查询条件；选项使用稳定身份；达到真实规模后再评估窗口化。

## C07 数字步进与滑块

- **适用条件：** 存在数量、区间、百分比、双滑块或可调参数时执行。
- **状态：** 覆盖最小、最大、越界、空值与无效；双滑块覆盖端点接近与约束冲突。
- **动作与反向中断：** 验证键入、步进、长按、拖动与滚轮；拖出边界、失去指针或取消编辑后值保持稳定。
- **语义键盘：** 按 slider 或 spinbutton 模式提供范围、当前值与各端点名称，并用值文本表达精度与单位。
- **验收：** 输入边界值与编辑中间态后失焦或提交；分别用键盘与指针设定同一结果；核对负数、小数、地区格式与序列化精度。
- **修复：** 统一边界与步长规则；显示单位与存储值分开；按明确规则钳制值；精确业务计算采用约定的数值表示。

## C08 日期与时间选择

- **适用条件：** 存在日期、时间、范围、预约或跨时区展示时执行。
- **状态：** 覆盖禁用日期与范围起止；跨时区或周期规则中覆盖跨日与夏令时边界。
- **动作与反向中断：** 验证手填、面板选取、清空、切月与取消；修改起点、语言或时区后核对终点与草稿。
- **语义键盘：** 为日历网格提供方向键导航并按当前语言组织周起始；弹层进入与关闭的焦点处理见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **验收：** 在两个已支持时区查看同一测试记录；输入闰日、逆序范围与边界时间；区分纯日期与绝对时间点后核对接口值与展示值。
- **修复：** 明确数据语义与业务时区；使用区域感知格式；生日等纯日期保持日期语义存储。

## C09 表单提交与分步向导

- **适用条件：** 组合多个字段执行保存、创建、配置或多步骤提交时执行。
- **状态：** 覆盖原始、已修改、校验失败、提交中、成功与失败；向导覆盖前进、返回、条件步骤与草稿恢复。
- **动作与反向中断：** 验证鼠标提交、Enter 提交、重置、取消、后退与刷新；超时后再次提交时的真实创建次数。
- **语义键盘：** 用分组与错误摘要把失败指向可修复字段；步骤当前位置以可感知语义表达。
- **验收：** 填到中途返回上一步，再使最终请求失败；确认输入保留、摘要能定位字段、创建次数符合契约。
- **修复：** 建立表单与提交状态机；客户端提示与服务端校验各自负责；条件隐藏字段同步移出提交值。

## C10 模态对话框

- **适用条件：** 当前交互要求阻断背景操作时使用；非模态浮层按 C12 检查。
- **状态：** 覆盖进入、打开与退出；异步确认中覆盖忙碌与失败，嵌套弹层中覆盖上层关闭。
- **动作与反向中断：** 验证触发、关闭按钮、取消、Esc 与背景点击策略；提交中关闭、触发点消失时的结果与焦点归宿。
- **数据布局：** 在长内容、小视口、放大文字与软键盘下保持标题、正文和必要操作可达。
- **验收：** 只用键盘打开、遍历并关闭；删除原触发对象后关闭，焦点仍有合理落点。
- **修复：** 复用原生 `<dialog>` 或项目经验证的模态实现，同时提供背景隔离、焦点边界与滚动处理；细节见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。

## C11 抽屉与侧面板

- **适用条件：** 存在侧栏详情、配置抽屉或可并行编辑面板时执行。
- **状态：** 在编辑面板中覆盖已修改，在响应式切换中覆盖模态与非模态模式。
- **动作与反向中断：** 验证切换记录、关闭、后退与调整宽度；保存未完成时切换目标，结果不写入错误记录。
- **语义键盘：** 是否阻断背景决定采用 dialog 还是普通区域语义；焦点边界要求见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **数据布局：** 检查主内容剩余宽度、双滚动、固定底部操作与小屏全屏展示。
- **验收：** 在两个实体之间快速切换再返回；缩至模式转换断点两侧；核对数据身份与未保存状态。
- **修复：** 把抽屉状态绑定实体 ID 与加载周期；按需重置局部状态；布局模式与交互模态分别定义。

## C12 浮层与操作菜单

- **适用条件：** 存在更多操作、上下文菜单、菜单按钮或非模态 popover 时执行。
- **动作与反向中断：** 覆盖忙碌、失败与权限改变项；验证触发、外部点击、Esc 与选择后关闭；滚动、窗口缩放与嵌套浮层不误触背景动作。
- **语义键盘：** 区分操作 menu、导航链接集合与表单 popover；采用菜单模式时实现其方向键与 roving focus。
- **数据布局：** 检查视口四角、图标与快捷键说明；定位、翻转与父容器裁切见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **验收：** 在表格最后一行打开菜单，滚动后用键盘选择；核对绑定实体未变、背景未意外执行。
- **修复：** 采用项目一致的定位与 dismiss 机制；统一顶层浮层挂载；按滚动与裁切根因修复。

## C13 工具提示与帮助说明

- **适用条件：** 存在 hover 说明、图标解释、截断文本提示或字段帮助时执行。
- **状态：** 覆盖延迟显示、键盘显示与消失；指针移入提示本体时保持可读且可关闭。
- **语义键盘：** 把补充描述关联到触发元素；含可交互内容时改用 popover 模式。
- **验收：** 不使用鼠标即可读取图标含义；在触摸设备上获得同等信息；提示不抢占焦点。
- **修复：** 必需信息改为常驻可见的帮助；校准显示与隐藏边界。

## C14 通知横幅与错误摘要

- **适用条件：** 用 toast、banner、alert 或摘要反馈保存、错误、连接与系统状态时执行。
- **状态：** 在并发事件中覆盖去重、堆叠、内容更新与已关闭后的重新出现规则。
- **动作与反向中断：** 验证关闭、重试、撤销与定位错误；超时消失、切页或重复到达时信息仍可找回。
- **语义键盘：** 按紧迫性选择播报方式，可操作通知保持键盘入口；live region 分级见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **验收：** 实际触发一次成功与一次失败；修复后旧错误不覆盖新状态。
- **修复：** 以事件或任务 ID 去重；为必须处理的信息提供持久入口；面向用户的文案只写可行动信息，服务端详情留在日志。

## C15 标签页与分段视图

- **适用条件：** 存在互斥内容面板、分段控制或外观近似标签页的导航时执行。
- **状态：** 在内容保留时覆盖切出再返回的局部状态；覆盖禁用标签与加载失败面板。
- **动作与反向中断：** 验证切换、快速往返与直接链接；未保存面板离开与异步内容迟到时的行为。
- **语义键盘：** 区分同页 tabs 与跨页链接；采用 tabs 时关联 tab 与 panel，并按自动或手动激活实现方向键与确认。
- **验收：** 用键盘切到加载较慢的标签再返回；核对当前面板、焦点、URL、草稿规则与溢出标签的入口。
- **修复：** 只让即时呈现的内容自动激活；用稳定身份管理面板状态；标签溢出时改用菜单入口。

## C16 全局导航侧栏与面包屑

- **适用条件：** 存在主导航、折叠侧栏、移动导航、面包屑或当前位置提示时执行。
- **状态：** 覆盖权限过滤后的菜单差异；异步菜单覆盖加载与失败，小屏覆盖抽屉模式。
- **动作与反向中断：** 验证深链接、刷新、前进后退与展开后跳转；导航关闭后主内容立即可操作，滚动锁定见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **语义键盘：** 站点导航用带名称的链接集合与当前位置语义，命令菜单才用 menu；提供跳过重复导航的路径；图标模式下仍提供名称。
- **验收：** 直接进入子路由，刷新后用键盘返回上级；窄屏打开、导航并关闭；核对当前位置。
- **修复：** 统一路由元信息；侧栏展开状态与当前路由分别拥有；入口准确性依赖服务端权限结果。

## C17 折叠区与展开控件

- **适用条件：** 存在 accordion、详情展开、更多内容或分组收起时执行。
- **状态：** 在懒加载内容中覆盖加载与错误；多项组合时明确允许同时打开的规则。
- **动作与反向中断：** 验证反复展开收起与展开后跳到内部链接；加载未完成或内部字段报错时收起再展开。
- **语义键盘：** 用可激活按钮或原生 disclosure 并同步 expanded；明确折叠时内容属于卸载还是隐藏。
- **验收：** 聚焦内部控件后按产品规则关闭父区；焦点不遗失、已填数据按约定保留、错误有可发现入口。
- **修复：** 按状态保留需要选择卸载或隐藏；只在需要互斥时实施单项展开；高度变化后保持阅读位置。

## C18 卡片列表与重复项目

- **适用条件：** 存在列表、卡片网格、可选记录或带行内操作的重复单元时执行。
- **状态：** 在可编辑列表中覆盖行级忙碌与局部失败；覆盖失效记录与选中项。
- **动作与反向中断：** 验证添加、删除、排序、选择与打开详情；重排后执行行操作时目标身份仍正确；明确整卡导航、行选择与子按钮各自的触发边界。
- **数据布局：** 测试混合高度、不同图片比例与大量内容；检查栅格断点与阅读顺序。
- **验收：** 让两项同名，删除其中一项并重排，再操作另一项；核对请求 ID、行级状态与焦点。
- **修复：** 使用稳定业务键；行级状态按实体管理；按实际密度选择列表或网格结构。

## C19 表格与交互数据网格

- **适用条件：** 存在表格、行选择、列排序、冻结列或单元格编辑时执行。
- **状态：** 在编辑与批量动作中覆盖无效、保存中、冲突与部分成功。
- **动作与反向中断：** 验证排序、筛选、翻页、列宽与行操作；编辑未提交时切页，选择后改变数据范围。
- **语义键盘：** 默认使用 table 结构、表头关系与排序状态；只有实现完整键盘模型时才采用 grid。
- **数据布局：** 测试长单元格、0 与空值、宽表、冻结列、双滚动与目标数据规模；核对格式、单位与对齐。
- **验收：** 选择行后排序翻页，再执行受控批量操作；核对真实选择范围、失败明细、键盘焦点与可见表头。
- **修复：** 固定行身份与列定义；明确服务端排序与分页契约；有性能证据时才虚拟化，并复查查找、打印、读屏与焦点。

## C20 树与层级选择

- **适用条件：** 存在文件树、组织树、层级权限或 treegrid 时执行。
- **状态：** 覆盖展开、折叠、选中、部分选中与无子项；懒加载中覆盖加载失败与子节点变化。
- **动作与反向中断：** 验证展开、选择、移动、删除与搜索定位；子树加载中收起、父节点失效后继续操作。
- **数据布局：** 检查深层缩进、重名、循环或非法层级数据与窄容器中的操作入口。
- **验收：** 仅用键盘展开到深层再删除当前节点；父级部分选中时加载新子项，核对选择策略。
- **修复：** 需要层级展开与选择时承担 tree 语义；分离节点身份、展开集合与选择集合；权限与层级合法性由接口保证。

## C21 搜索与联想结果

- **适用条件：** 存在提交搜索、即时搜索、历史词或联想建议时执行。
- **状态：** 保留旧结果时清楚表达其过期状态；覆盖无结果、失败与清空。
- **动作与反向中断：** 验证连续改词、清空、提交与选中建议；让旧查询晚于新查询返回。
- **语义键盘：** 提供搜索名称与结果数量状态；只有真正联想时才采用 combobox 组合；逐字符输入不抢焦点。
- **验收：** 连续提交 A、B 并颠倒返回次序，确认最终显示 B；清空后不被迟到响应重新填满。
- **修复：** 按业务选择提交或防抖；请求绑定查询版本；取消或忽略旧响应；高亮片段以文本节点拼接。

## C22 筛选排序与条件标签

- **适用条件：** 存在过滤面板、筛选 chip、多条件查询、重置或保存视图时执行。
- **状态：** 区分草稿条件、已应用条件、空条件与“全部”四种含义；覆盖无结果、查询失败与已修改视图的保存冲突。
- **动作与反向中断：** 验证应用、取消、单项移除、全部重置与后退；改筛选时核对分页、选择范围与旧结果。
- **语义键盘：** 每个条件与移除动作有可区分名称；参与选择的用 toggle，仅展示的保持静态标签。
- **验收：** 应用组合条件后刷新、分享或后退，按产品承诺核对恢复；移除聚焦标签后确认焦点落点。
- **修复：** 分离草稿与生效查询；统一 URL、接口与本地序列化；改变数据域时显式重置分页与批量选择。

## C23 分页加载更多与无限滚动

- **适用条件：** 数据规模需要分段展示，且存在页码、游标或追加加载时执行。
- **状态：** 在数据总数改变时检查当前页合法性；覆盖末页、无更多与加载失败。
- **动作与反向中断：** 验证翻页、改每页数量、连续加载、刷新与后退；请求未完成时换筛选或再次触发。
- **数据布局：** 检查不足一页、零总数、未知总数与动态行高；加载指示不改变滚动锚点造成跳跃，并保留可键盘到达后续内容的路径。
- **验收：** 在末页删除一条记录，再切筛选并让旧加载返回；核对无重复、无遗漏与合理当前位置。
- **修复：** 按接口契约选择页码或游标；按稳定 ID 去重；明确追加、替换与失效策略；规模允许时保持整页可跳转。

## C24 拖拽排序与分栏调整

- **适用条件：** 存在拖放移动、排序、画布拖动或可调整分栏时执行。
- **动作与反向中断：** 覆盖可拖、拖动中、有效与无效目标、完成与取消；验证拖出边界、自动滚动、放回原处、Esc、指针取消与快速反向调整；检查触摸滚动冲突。
- **语义键盘：** 为排序提供点击式替代入口并表达完成结果；面板调整的键盘路径见 [visual-accessibility-performance.md](visual-accessibility-performance.md)。
- **数据布局：** 检查滚动容器、缩放、横竖方向、最小面板宽度与长条目；坐标换算覆盖非默认缩放。
- **验收：** 通过替代入口完成同一移动；拖到容器边缘后取消；核对顺序、焦点、保存结果与鼠标路径一致。
- **修复：** 统一指针与取消生命周期；用稳定 ID 与显式目标位置；按规则约束合法范围。

## C25 上传区与附件队列

- **适用条件：** 允许选择文件、拖入、粘贴文件、批量上传或断点上传时执行。
- **状态：** 覆盖待选、校验、排队、上传、处理、成功、失败与取消；仅在支持断点续传时检查恢复。
- **动作与反向中断：** 验证重复选同一文件、同名不同文件、移除、重试、取消与导航；断网后队列身份仍可核对；除拖入之外保留可访问的点击选择入口。
- **数据布局：** 检查零字节、边界大小、扩展名与内容不一致、批量部分失败与缺失缩略图。
- **验收：** 上传一项合法与一项不合法文件，取消后重试；核对文件 ID、最终结果与正文仍可编辑。
- **修复：** 区分传输完成与服务端处理完成；释放预览资源；重试沿用同一文件身份；服务端类型、大小与对象权限校验见 [security-delivery.md](security-delivery.md)。

## C26 富文本与代码编辑器

- **适用条件：** 存在富文本、Markdown、代码编辑、差异视图或可编辑文档时执行。
- **状态：** 覆盖只读、已修改、保存中与失败；协作场景覆盖冲突与外部更新。
- **动作与反向中断：** 验证粘贴、撤销重做、选择复制、快捷键与切文档；保存中关闭后的草稿归属。
- **数据布局：** 测试长行、超长文档、代码围栏、表格、图片失效与缩放；核对行号、选区、滚动与浮层位置。
- **验收：** 在组合输入中触发工具栏操作再撤销；切到另一文档后让旧保存返回；核对文档身份、内容与选区。
- **修复：** 利用编辑器事务与文档模型；分离渲染内容与存储源；明确保存版本与冲突策略；编辑区退出路径与快捷键保留见 [visual-accessibility-performance.md](visual-accessibility-performance.md)，输出清洗见 [security-delivery.md](security-delivery.md)。

## C27 图表与数据可视化

- **适用条件：** 使用图表、地图、仪表或可交互可视化表达数据时执行。
- **状态：** 覆盖选择与图例关闭；实时更新覆盖暂停、滞后与断线。
- **动作与反向中断：** 验证悬停、键盘或替代查询、图例、缩放与重置；过滤或 resize 后选中对象仍一致。
- **数据布局：** 检查零值、负值、缺失、异常值、不同量级与单位；坐标起点与聚合方式如实反映数据，必要数值不只靠颜色或 hover 传递。
- **验收：** 用含空值、负值与极端值的可核对样本比对图中结果；缩小容器并通过非 hover 方式取得关键数据。
- **修复：** 固定数据映射与单位规则；按实际数据量选择抽样、聚合或渲染；写明抽样语义并提供数据表等等价路径。

## C28 图片视频与轮播

- **适用条件：** 展示用户图片、封面、音视频、自动轮播或可放大媒体时执行。
- **状态：** 覆盖加载、失败与占位；播放器覆盖播放、暂停、缓冲、结束与格式或权限失败。
- **动作与反向中断：** 验证播放暂停、跳转、放大、切图与关闭；路由离开、后台或媒体失效时的声音与资源。
- **数据布局：** 检查宽高比、裁切焦点、低分辨率、竖图、字幕遮挡与尺寸预留。
- **验收：** 让一个媒体 URL 失败并切换视口；用键盘播放暂停；离开页面后无残留音频与不可关闭浮层。

## C29 加载空白错误与占位单元

- **适用条件：** 任何依赖异步数据、首次使用引导或可能失败的区域均执行。
- **状态：** 区分首次加载、后台刷新、无数据、无匹配、无权限、部分失败与全局失败，各自给出下一步。
- **动作与反向中断：** 验证重试、创建、返回、保留旧内容与离线恢复；区域卸载后收到结果时的状态污染。
- **语义键盘：** 给忙碌区域与状态变化适当语义；骨架内容不含可聚焦节点；重试与替代路径可达。
- **验收：** 分别返回零条、拒绝访问、网络失败与部分数据；核对文案、可执行下一步、旧数据标签与实际请求状态。
- **修复：** 建立明确结果类型；区分请求错误与业务空集；用错误隔离保留可用区域；异步区有可判定终态。

## C30 AI流式消息与工具结果

- **适用条件：** 展示逐步生成文字、工具调用、引用、富消息或多轮 AI 会话时执行。
- **状态：** 覆盖等待首段、接收中、工具运行、完整、截断、失败与取消；支持恢复时检查重连与补发。
- **动作与反向中断：** 验证停止、重试、重新生成、复制、切会话与历史滚动；让旧流在新会话打开后继续返回。
- **数据布局：** 检查未闭合 Markdown、代码围栏、公式、长链接、大段内容与混合附件；复制结果对应当前消息版本。
- **验收：** 用受控流拆分字符与协议帧，注入断流与重复事件；切换会话并停止；核对消息身份、无乱码与结束原因。
- **修复：** 给消息作者与工具状态命名，保留阅读位置并提供返回最新入口（见 [visual-accessibility-performance.md](visual-accessibility-performance.md)）；协议解析、重放去重与取消语义见 [state-data.md](state-data.md)；模型输出按不可信内容清洗见 [security-delivery.md](security-delivery.md)。

## C31 长任务进度与运行控制

- **适用条件：** 管理训练、解析、导出、批处理、Agent 执行或持续运行任务时执行。
- **状态：** 区分排队、启动、执行、待输入、成功、失败、取消中、已取消与状态未知；百分比只在服务端提供时显示。
- **动作与反向中断：** 验证刷新、重连、重试、取消与查看日志；完成与取消同时到达时核对终态。
- **语义键盘：** 给进度与控制提供名称；未知进度表达为不确定状态；日志的暂停、复制与恢复跟随可操作性。
- **验收：** 创建隔离任务并保留 ID；在提交响应丢失后查询而非盲目重建；刷新并取消，核对界面与服务端终态一致。
- **修复：** 将取消请求与取消确认分开表达；作业身份、状态机与取消协议见 [state-data.md](state-data.md) 与 [security-delivery.md](security-delivery.md)。

## C32 文件预览下载与导出

- **适用条件：** 存在文档预览、图片放大、下载链接、报表导出或批量导出时执行。
- **状态：** 覆盖准备、生成、可下载、失败、链接过期与无预览；大文件覆盖分段载入或明确限制。
- **动作与反向中断：** 验证预览、翻页、缩放、下载、取消与重新生成；权限变化或链接过期后重新操作。
- **数据布局：** 检查长文件名、页面比例、大表格、字体缺失与分页；核对导出范围、时区、单位与界面筛选一致。
- **验收：** 下载并实际打开隔离样本；比对文件内容与记录数；使临时链接过期，核对恢复入口与错误反馈。
- **修复：** 区分下载开始、生成完成与文件可用；管理临时资源生命周期；不可访问的预览提供等价内容或原文件入口；链接授权与公式注入见 [security-delivery.md](security-delivery.md)。
